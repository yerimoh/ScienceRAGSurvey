M4 Verification

Construction Retrieval Integration Verification

Generation produces an output, but in science that output is trusted only to the extent it has been checked against something beyond the retrieved evidence. Verification is the stage that performs this check, and systems differ in how deeply the verifier is coupled to generation. This coupling is the depth at which an external verifier of the pipeline equation enters the generation loop, from a system that adds no external check to one that refines against a verifier at every step. This depth tends to bound the highest objective a system can reach, since an output is trusted to the extent it has been verified. We read it as a ladder of four rungs of increasing coupling. In terms of the pipeline equation, the rungs fix the verifier and the depth: open generation runs once with no verifier, self-check keeps internal to the retrieved evidence, external verification applies an outside once, and closed-loop refinement runs an outside for.

Open generation

The shallowest coupling is no coupling at all, a system that retrieves and generates once and returns the result unchecked. This is enough whenever the answer already lies inside the retrieved evidence, so the generator has only to report it. MEDRAG and HiPerRAG answer a question straight from the passages they retrieve, GeneGPT grounds each answer in the exact value an NCBI web-service call returns, and MADGEN recovers a molecular structure from a mass spectrum in a single spectrum-conditioned pass. Open generation suffices whenever a gold already fixes the answer, whether a Question Answering label or the held-out structure of spectrum-to-molecule Property Prediction, and stops there, because it asserts nothing a gold cannot already check.

Self-check

A self-checking system reads its own draft before committing to it, but the only thing it consults is the evidence it already retrieved, never the outside world. Self-BioRAG rates the relevance and support of each passage with reflective tokens, and PaperQA enforces that every statement stays faithful to a cited source. Because the check never leaves the retrieved evidence, this rung supports Question Answering and much of Literature Synthesis, yet it cannot establish a claim the evidence does not already contain.

External verification

An externally verified system sends its finished output to an outside process that scores it once, so the judgment comes from beyond the retrieved evidence. IRDiff scores each generated 3D molecule by docking against the target once, and Rag2Mol screens its generated candidates through docking and drug-likeness filters after generation, neither refining against the result. This outside check is what underwrites docking-scored Molecular Design, where a candidate is confirmed against a target the model was not shown.

Closed-loop refinement

The deepest coupling runs the verifier inside the generation loop and revises the output against its verdict round after round. Three drug-design systems close this loop around a docking oracle. f-RAG scores each assembled fragment set by docking and steers its fragment vocabulary toward higher-scoring molecules, RetMol returns each newly generated molecule that improves its AutoDock-GPU score to the retrieval database it draws from, and TaLiRAGen feeds docking scores back into a training-free prompting loop. A high-entropy-catalyst system closes a slower but stronger loop, validating each round of proposed alloys with a density-functional-theory calculation. The loop is not limited to structure-based design, since KGARevion generates candidate triples, reviews each against a knowledge graph, and revises over several rounds before it answers. Placing the verifier in the loop is what makes docking-verified Molecular Design and simulation-verified Materials Discovery reachable, since only a candidate that survives repeated checking is proposed.

Verifier coupling both enables and caps a system's reach beyond the corpus. A system with no external verifier can propose a novel candidate but cannot certify it, so its evaluation measures only resemblance to prior work and never establishes that the candidate is correct.
