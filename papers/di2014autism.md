#### 📌 한 줄 요약
전세계 다기관 컨소시엄이 자폐 스펙트럼 장애(ASD) 연구를 위해 공개 공유한 1,112건의 안정 상태 fMRI 데이터셋으로, ASD의 내인성 뇌 구조 특성을 대규모로 평가하는 최초의 신경영상 공개 데이터베이스.

#### 🎯 개발/구축 배경
**기존 인프라의 한계**
- ASD 신경영상 연구가 소규모 단일 기관 연구에 한정 — 높은 이질성으로 재현 불가
- 유전학 분야와 달리 신경영상은 데이터 공유 문화 미성숙
- ASD의 복잡성과 높은 유병률에 비해 대규모 데이터 부재

**이 시스템이 필요한 이유**
- ASD 신경생물학 이해 가속화를 위한 대규모 다기관 데이터 필요
- 복제 가능성과 새로운 발견을 동시에 입증할 플랫폼 필요

#### 🔨 시스템 구성
국제 다기관 컨소시엄이 기존 안정 상태 fMRI 데이터를 집계·공개 공유. ASD 539명, 정상 대조 573명(7–64세) 포함. 구조적 MRI와 표현형 정보 포함. 분석 샘플: ASD 남성 360명 + 정상 대조 남성 403명. 전뇌 내인성 기능 연결성 분석 및 복셀 단위 뇌 기능 지표 조사. 저연결성(특히 피질간·반구간)이 과연결성보다 우세; 공통 기능 이상 부위: 중앙/후방 섬엽, 후방 대상 피질.
