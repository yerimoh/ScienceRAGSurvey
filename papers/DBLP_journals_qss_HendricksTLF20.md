# Crossref: The sustainable source of community-owned scholarly metadata

> Quantitative Science Studies | 2020 | dataset | general

## 한 줄 요약
연 **11% 성장하며 1억 600만 개 이상**의 레코드를 보유한 커뮤니티 소유 학술 메타데이터 인프라로, 저널·컨퍼런스 논문·데이터셋·프리프린트·피어리뷰·그랜트 등 **13개 콘텐츠 유형**에 걸쳐 인용 링크·펀딩·라이선스 정보를 REST API와 OAI-PMH로 제공한다.

## 연구 배경 및 동기
**기존 메타데이터 인프라의 한계**
- 학술 출판사별로 메타데이터 형식·접근 방식이 파편화되어 있고, 인용 연결과 연구비 정보의 공개 집계가 부재했음
- 지속 가능하고 커뮤니티가 공동 소유하는 오픈 인프라의 필요성 대두

**Crossref의 역할**
- 출판사·기관·연구자 모두가 기여하고 활용하는 **커뮤니티 소유(community-owned)** 모델로 운영
- 계측학(scientometrics) 연구를 포함한 학술 생태계 전반의 핵심 데이터 소스로 자리잡음

## 핵심 기능
| 기능 | 설명 |
|---|---|
| DOI 등록 및 조회 | 1억 600만 개 이상 레코드, 무료 REST API |
| 다양한 콘텐츠 유형 지원 | 저널·컨퍼런스 논문 외에도 데이터셋·리포트·프리프린트·피어리뷰·그랜트 등 13종 |
| 풍부한 메타데이터 | 초록, 전문 링크, 펀딩 정보, 라이선스 정보, 인용 링크, 정오표·업데이트·철회 정보 |
| 인용 데이터 제공 | 인용 관계 링크 제공 (제공 이력 및 진화 과정 논문에서 기술) |
| REST API | `api.crossref.org` — 무료, 회원가입 불필요 |
| OAI-PMH | 메타데이터 수확(harvesting)을 위한 표준 프로토콜 지원 |

## 데이터 규모 (2020년 논문 기준)
- **총 레코드 수**: 1억 600만 개 이상 (over 106 million records)
- **연간 성장률**: 평균 11%
- **콘텐츠 유형 수**: 13개
- **접근 방식**: REST API, OAI-PMH

## 커뮤니티 소유 모델
- Crossref는 출판사·학회·기관 등 다수의 멤버로 구성된 커뮤니티가 공동으로 소유·운영하는 비영리 메타데이터 인프라
- 멤버들이 직접 메타데이터를 등록(deposit)하고, 동일한 인프라를 활용하는 상호 기여 구조
- 이 논문은 메타데이터가 어떻게 수집·큐레이션되는지, Crossref가 연구 생태계에서 담당하는 역할, 그리고 메타데이터 품질 및 인용 데이터 제공의 역사적 진화를 서술

## 한계점
- 메타데이터의 완전성(completeness)은 개별 멤버의 등록 품질에 의존하므로 불균일
- 논문에서 메타데이터 품질 및 검색 기능 개선 계획을 "미래 과제"로 명시
- 일부 콘텐츠 유형(예: 그랜트, 피어리뷰)은 기존 저널 논문 대비 등록 비율이 낮을 수 있음
