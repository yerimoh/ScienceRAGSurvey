GeoGPT-RAG Technical Report

arXiv | 2025 | Benchmark · Method | earth

TL;DR

Develops an RAG stack dedicated to the geoscience domain (GeoEmbedding, GeoReranker, RAFT) and releases GeoRAG-QA, a 938-item QA benchmark automatically generated from 1,000 open-access geoscience papers using a GPT-4o + RAGAS framework. Achieves a Top-1 retrieval recall of 0.908 and 85.7% answer accuracy under expert evaluation.

Background

Limitations of existing benchmarks

  • General-purpose IR benchmarks such as MTEB and BEIR are ill-suited to geoscience material, which has a highly specialized vocabulary and structure, as in geology, petroleum exploration, and geophysics
  • There was no standard benchmark for objectively comparing retriever performance in geoscience RAG evaluation
  • In the geoscience domain, where high-quality labels are scarce, the synthetic data generation and quality control pipeline is itself a research challenge

Why this system and benchmark were needed

  • Because GeoGPT must support a geoscience domain on the scale of 1M+ papers from 38 countries, a domain-adapted embedding/reranker is essential
  • Non-experts and junior researchers must also be able to accurately retrieve and synthesize geoscience information via RAG

Construction Methodology

Overall composition: GeoGPT library → RAGAS-based automatic QA generation → manual review → GeoRAG-QA 938 released

Step 1 — Source corpus construction
  Randomly sample 1,000 open-access geoscience papers
  from the GeoGPT library (public library 15 million vectors,
  user library 3 million vectors)

Step 2 — Automatic QA pair generation (RAGAS Test Set Generation)
  ┌─ LLM: GPT-4o (question/answer generation)
  └─ Embedding: text-embedding-3-small (similarity verification)

  Generate 1,000 questions across 4 question types
  ┌────────────────────────────────┬──────┐
  │ Single-document fact-based     │  250 │
  │ Single-document inference      │  250 │
  │ Multi-document                 │  188 │
  │ Conditional                    │  250 │
  └────────────────────────────────┴──────┘

Step 3 — Manual quality verification
  Remove 62 defective items
  "The answer is not present in the context" items → regenerate with GPT-4o
  → final 938 QA released

Step 4 — Retrieval system training
  ┌─ GeoEmbedding: Mistral-7B-based decoder-only encoder
  │  - 360k training samples + Qwen synthetic geoscience data
  │  - LoRA r=8, α=16, in-batch negatives, InfoNCE loss
  └─ GeoReranker: BGE-M3-based cross-encoder
     - 30k geoscience + 360k general pairs
     - 0–3 quality labeling with LLaMA3, label 0 excluded
     - SimANS hard-negative mining

Step 5 — Evaluation (GeoRAG-QA 938 / 70 expert)
  Top-K Recall (automatic 938) + Answer Recall (RAGAS)
  + Expert accuracy on 70 petroleum exploration Qs

Note: GeoRAG-QA is an open-ended free-text benchmark. Answers are free-form sentences rather than MC options, and the evaluation metrics are RAGAS's Answer Recall and Top-K Recall.

Input

Item Content
Source corpus 1,000 randomly sampled papers from the GeoGPT library
Chunk splitting NLTK + BERT-NSP-based 512-token semantic segmentation
Embedding GeoEmbedding (Mistral-7B encoder conversion, 4,096 token context)
Vector DB Zilliz Cloud (Milvus) — 15 million public + 3 million user vectors

GeoRAG-QA composition itself

Question type # items Avg. retrieval score Retrieval success rate

Single-document inference 250 0.805 246/250
Multi-document 188 0.874 188/188
Conditional 250 0.820 247/250

Output (answer format)

Answers in the form of text generated by the model. The evaluation metrics are Answer Recall (RAGAS) + Top-K Recall + expert answer accuracy (70Q).

Example items (as stated in the paper body)

This paper does not cite specific QA instances in the body. Instead, it directly cites the prompt templates used for question generation and the type categories (Table 6). Specific Q/A examples can be found in the publicly released HuggingFace dataset (GeoRAG-QA).

📘 Query-Generation Prompt (verbatim from the body)

"Instruction: Given the next [document], create a [question] and [answer] pair that are grounded in the main point of the document, don't add any additional information that is not in the document and [use prompt by different query type of Table 6]. The [question] is by an information-seeking user and the [answer] is provided by a helping AI Agent."

📘 Query Type Categories (Table 6)

"What / Which / Who·Whose / When / Where / How / Why / General question / Imperative question — The question should use [q_word]... to ask. Please ask in general form. Use imperative sentences to prompt the text."

📘 Answer-Rewriting Prompt

"Your generated answer should contain 6 to 8 sentences. Your generated answer should have exactly the same meaning as the [Short Answer] and must perfectly address the [Query] without deviating. The content of your generated answer should fully utilize the content from the [References], and you must not fabricate any facts."

📘 Expert evaluation domain

"We further conducted manual evaluation on 70 domain-specific questions related to petroleum exploration. These questions were reviewed by subject matter experts to assess the factual accuracy of the generated answers." → Expert evaluation accuracy: 85.7% (Table 4)

Limitations

  • GeoRAG-QA is synthetic QA reverse-generated by GPT-4o — it differs from the natural distribution of questions that real domain experts would ask spontaneously
  • Only 1,000 open-access papers were sampled → access-restricted journals are not covered
  • The concrete definition and generation protocol for the 250 Conditional QA items is unclear
  • Direct benchmarks for retrieval latency and operating cost are not included
