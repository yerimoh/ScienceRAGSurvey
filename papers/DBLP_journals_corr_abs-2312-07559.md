# PaperQA: Retrieval-Augmented Generative Agent for Scientific Research

> arXiv 2023 | Method + Benchmark | bio · medical
> Jakub Lála, Odhran O'Donoghue, Aleksandar Shtedritski, Sam Cox, Samuel G Rodriques, Andrew D White (Future House / Francis Crick Institute / University of Rochester)

## TL;DR
An agent-based RAG system, **PaperQA**, that dynamically retrieves, extracts, and summarizes scientific literature to generate expert-level answers with 0% citation hallucination, together with the **LitQA** benchmark (50 MC biomedical questions) proposed to evaluate it.

---

## LitQA Benchmark — How It Was Built (Construction Methodology)

```
Step 1 — Source paper selection
  Select only biomedical papers published after the LLM training data cutoff (September 2021)
  → Turn into questions only knowledge absent from the model's parametric memory

Step 2 — Question generation principle
  "Select a paper and devise a question that:
   (1) refers to a novel finding in the paper body
   (2) is NOT present in the abstract"
  → Questions written by expert biomedical researchers

Step 3 — Distractor (incorrect-choice) generation
  Generated directly by the question author OR
  Plausible incorrect-answer candidates generated by an LLM and then reviewed

Step 4 — Peer review
  Finalized after independent cross-review by co-authors

Step 5 — Final composition
  ┌──────────────────┬──────┐
  │ Number of choices │ Count │
  ├──────────────────┼──────┤
  │ Yes/No (2-way)    │    5 │
  │ 3-way choice      │    6 │
  │ 4-way choice      │   23 │
  │ 5-way choice      │   10 │
  │ 6-way choice      │    4 │
  │ 7-way choice      │    2 │
  ├──────────────────┼──────┤
  │ Total             │   50 │
  └──────────────────┴──────┘
  Domain: biomedical
  Evaluation metrics: Accuracy (Correct/All), Precision (Correct-Sure/Answered-Sure)
```

## Actual Question Examples (Directly Quoted from the Paper Body)

### Easy Question (Yes/No)
> **Q.** Has anyone performed a base editing screen against splice sites in CD33 before?
>
> **(A) Yes  (B) No**
>
> → A factual question whose answer can only be found in the body of a paper published after September 2021

### Medium Difficulty (3-way choice)
> **Q.** How diffuse are the laminar patterns of the axonal terminations of lower Layer 5/Layer 6 intratelencephalic neurons compared to Layer 2-4 intratelencephalic neurons in mouse cortex?
>
> **(A) More diffuse  (B) About the same  (C) Less diffuse**

### Hard Question (4-way choice, negation form)
> **Q.** Which of these glycoRNAs does NOT show an increase in M0 macrophages upon stimulation with LPS: U1, U35a, Y5 or U8?
>
> **(A) U8  (B) U1  (C) U35a  (D) Y5**

## PaperQA System Architecture

```
[User question]
      │
      ▼
┌─────────────────────────────────────────┐
│  Agent LLM (GPT-4, τ=0.5)              │
│  "Iterate until enough evidence (5+)     │
│   has been gathered"                     │
└──────┬──────────────────────────────────┘
       │ tool selection & invocation
  ┌────┴─────┬──────────────────┐
  ▼          ▼                  ▼
[Search]  [Gather Evidence]  [Answer Question]
  │          │                  │
  │  by      │  MMR vector      │  Ask LLM
  │  keyword │  search          │  (parametric knowledge)
  │  ArXiv/  │  → Summary LLM   │  + 8 pieces of gathered evidence
  │  PubMed  │    (GPT-3.5)     │  → Answer LLM (GPT-4)
  │  search  │    relevance     │  → final answer with citations
  │          │    scored 1-10   │
  │          │    top filtering │
  ▼          ▼                  ▼
4,000-char chunks  20 sources/round   "(Author2023)"-style citations
text-embedding-ada-002 vectorization
```

Runs 4 independent LLM instances:
| Role | Model | Role description |
|---|---|---|
| Agent LLM | GPT-4 (τ=0.5) | Tool selection, decides whether to iterate |
| Summary LLM | GPT-3.5-turbo (τ=0.2) | Chunk summarization + relevance scoring |
| Answer LLM | GPT-4 (τ=0.5) | Final answer generation with citations |
| Ask LLM | GPT-4 (τ=0.5) | Parametric knowledge extraction |

## Key Evaluation Results

### LitQA Accuracy Comparison
| System | Correct | Incorrect | Unsure | **Accuracy** |
|---|---|---|---|---|
| **PaperQA** | **34.8** | **4.8** | **10.5** | **69.5%** |
| Human expert | 33.4 | 4.6 | 12.0 | 66.8% |
| Claude-2 | 20.3 | 26.3 | — | 43.6% |
| GPT-4 | 16.7 | 16.3 | 17.0 | 33.4% |
| Perplexity | 9.0 | 10.0 | 31.0 | 18.0% |

→ PaperQA ≈ human expert (Cramér's V: human-human 0.66±0.03 vs human-PaperQA 0.67±0.02)

### Citation Hallucination Rate
| Model | Valid citations | **Hallucination** | Sample |
|---|---|---|---|
| **PaperQA** | **100%** | **0%** | 237 |
| GPT-4 | 60.78% | 39.22% | 51 |
| GPT-3.5 | 52.50% | 47.5% | 80 |
| Claude-2 | 39.71% | 60.29% | 68 |

### Standard Benchmarks (Including Ablation)
| Configuration | MedQA-USMLE | BioASQ | PubMedQA |
|---|---|---|---|
| **PaperQA** | **68.0%** | **89.0%** | **86.3%** |
| GPT-4 alone | 67.0% | 84.0% | 57.9% |
| AutoGPT | 54.0% | 73.0% | 56.8% |

## Limitations
- Cannot cope when the information in the cited original paper is itself incorrect
- Answer validity-period problem due to updates in the latest facts
- Average cost per question $0.18 (as of 2023)
