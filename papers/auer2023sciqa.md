# The SciQA Scientific Question Answering Benchmark for Scholarly Knowledge

> Scientific Reports 2023 (13:7240) | Benchmark | chem · bio · medical · earth · CS
> Auer, Barone, Bartz, Cortes, Jaradeh, Karras, Koubarakis, Mouromtsev et al. — TIB Hannover / Athens / ITMO

## 한 줄 요약
ORKG(Open Research Knowledge Graph)에 등재된 학술 비교(comparison) 데이터를 바탕으로 **100개 수작업 + 2,465개 자동 생성 = 2,565개**의 자연어 질문과 SPARQL 쿼리 쌍을 짝지어 만든 학술 KG-QA 벤치마크. ISWC 2023 QALD-12 챌린지 공식 데이터셋으로 채택되었으며, ChatGPT는 100 수작업 질문 중 단 **14개만 정답**을 맞춰 학술 KG에 대한 LLM의 추론 한계를 드러냄.

## 제작 배경
- **기존 KG-QA 벤치마크 한계**: WebQuestions(5,810/Freebase), SimpleQuestions(108k/Freebase), LC-QuAD/LC-QuAD 2.0(5k–30k/DBpedia·Wikidata), QALD-10(394/Wikidata) 등은 **백과사전적 사실 지식** 중심.
- 학술 커뮤니케이션은 (a) 지식 표현의 이질성, (b) 과학 담론에 따른 개념 진화, (c) 다양한 세분화 수준, (d) 단순 엔티티를 넘어선 비교/집계 구조를 띠어 기존 KG-QA로 평가 불가.
- 본 논문 명시(p.7): SciQA는 "scholarly knowledge"의 비교·집계·superlative 질문에 특화된 **최초의 KG-QA 벤치마크**.

## 어떻게 만들었나 (Construction Methodology)

```
Step 0 — 지식 소스: ORKG
  Open Research Knowledge Graph (https://orkg.org)
  ├─ ~170,000 resources
  ├─ ~15,000 paper contributions의 의미론적 기술
  └─ 핵심 추상화: "Comparison" (다수 논문의 contribution 표 비교)

Step 1 — 수작업 100문항 (Handcrafted)
  ┌─ 13명 저자 + 21명 도메인 전문가 (5개국 3개 대륙)
  ├─ ORKG comparison 선정 (여러 연구 분야 망라)
  ├─ 자연어 질문 작성 (single comparison / True/False / aggregation)
  ├─ SPARQL 쿼리 두 버전(human-readable / machine-readable) 작성
  ├─ 메타데이터 수집 (type / query shape / 등)
  └─ 다중 peer review (syntactic + semantic correctness)

Step 2 — 자동 생성 2,465문항 (Autogenerated)
  ┌─ 대상: 'papers-with-code' 데이터 (CS, 균일 기술로 이질성 최소)
  ├─ 8개 SPARQL 쿼리 템플릿 작성
  ├─ GPT-3로 32개 질문 변형 생성
  ├─ ORKG 엔티티로 placeholder 채워 (2,465 = 8 templates × variations × instances)
  └─ 메타데이터 자동 부여 (Tree shape, Factoid/Non-factoid 등)

Step 3 — 통계 (Table 3·4)
  ┌─────────────────┬───────────┬───────────────┐
  │                 │Handcrafted│ Autogenerated │
  ├─────────────────┼───────────┼───────────────┤
  │ Total queries   │    100    │     2,465     │
  │ Research fields │     ~20   │       1 (CS)  │
  │ Query shapes    │           │               │
  │   Tree          │     76    │     2,465     │
  │   Chain         │     20    │         0     │
  │   Star          │      3    │         0     │
  │   Other         │      1    │         0     │
  │ Query types     │           │               │
  │   Factoid       │     61    │     2,122     │
  │   Non-factoid   │     39    │       343     │
  │     Superlative │     26    │         0     │
  │     Temporal    │      3    │         0     │
  │     Count       │      7    │         0     │
  │ Components(med) │      6    │         6     │
  │ Triple patt.(med)│     5    │         6     │
  └─────────────────┴───────────┴───────────────┘

Step 4 — 공개
  ├─ Zenodo: doi.org/10.5281/zenodo.7729047
  ├─ HuggingFace: huggingface.co/datasets/orkg/SciQA
  └─ ISWC 2023 Scholarly QALD challenge 공식 데이터셋
```

## Input (입력)
- **자연어 질문** (영어)
- **SPARQL 쿼리** (machine-readable + human-readable identifiers 두 버전)
- **ORKG snapshot** (질의 대상 데이터)
- **메타데이터**: question type, query shape (Tree/Chain/Star/Forest/Edge/Cycle), query components (SELECT, ASK, COUNT, FILTER, REGEX, STR…), triple pattern 개수

## Output (출력 / 정답 형식)
- **답변 형태**: SPARQL 실행 결과 (텍스트, 수치, 리스트, Boolean)
- **평가 지표**:
  - JarvisQA: Precision@k, Recall@k, F1@k (single-answer / overall 카테고리)
  - LLM(ChatGPT): 전문가 교차 평가의 4단계 정성 (Correct / Incorrect / Uncertain / No answer)

## 예시 문항 (논문 p.8–10 직접 인용)

### Handcrafted Q1 — Aggregation (Energy Systems / Mechanical Engineering)
> **NL Q:** *"What is the average energy generation for each energy source considered in 5-year intervals in Greenhouse Gas Reduction Scenarios for Germany?"*
>
> - SciQA-Handcrafted ID 55
> - ORKG comparison: "Greenhouse Gas Reduction Scenarios for Germany" (저탄소 전력 시스템 분석 논문들)
> - SPARQL: 7 triple patterns, 8 query components, Tree shape
> - 답변 유형: average across 5-year intervals × multiple energy sources
> - 도메인 전문가 검증: "average values are needed for trend analysis"

### Handcrafted Q2 — Most-Frequent (Databases / CS)
> **NL Q:** *"What is the most common knowledge representation method in Semantic Representations of Scholarly Communication?"*
>
> - SciQA-Handcrafted ID 3
> - ORKG comparison: "Semantic Representations of Scholarly Communication"
> - SPARQL: 3 triple patterns, 7 components, Chain shape
> - **Ground truth answer: RDF (Resource Description Framework)**

### Handcrafted Q3 — Superlative (Ecology & Biodiversity / Zoology)
> **NL Q:** *"Where did the study with maximal geographic scale take place in Genetic Variability (COI Variation) in Studies Large Sampled (>1000 Sequences)?"*
>
> - SciQA-Handcrafted ID 78
> - ORKG comparison: cytochrome c oxidase I (COI) barcoding 연구들
> - SPARQL: 6 triple patterns, 6 components, Tree shape
> - **Ground truth answer: USA, Mexico, Canada (북미 3국 다국가 연구)**

### Autogenerated Q4 — Superlative (papers-with-code / CS)
> **NL Q:** *"Can you provide the highest benchmark result, including the metric and score, for the Sequential MNIST dataset?"*
>
> - SciQA-Autogenerated ID 1355
> - SPARQL: 10 triple patterns, 9 components, Tree shape
> - 평가 메트릭별 best score를 distinct하게 fetch

### Autogenerated Q5 — Factoid List (papers-with-code / CS)
> **NL Q:** *"List the title and ID of research papers that contain a benchmark over the SST-2 Binary classification dataset?"*
>
> - SciQA-Autogenerated ID 524
> - SPARQL: 6 triple patterns, 4 components, Tree shape
> - 답변: paper title + paper ID 리스트

## 주요 평가 결과

### JarvisQA (학술 테이블 특화 BERT-기반 시스템)
- 100 수작업 질문 중 **52개만** JarvisQA 입력 형식과 호환 (table-only)
- 최고 설정 **JarvisXLS2**: 단 **12개 정답** (12% of 100)
- single-answer "normal" 카테고리에서는 더 높은 P/R/F1이나, listing·boolean까지 포함한 "overall" 카테고리에서는 전반적 하락

### ChatGPT (preliminary)
- 100 수작업 질문 중 **63개에 답변 제공**, **37개 무응답**
- 전문가 교차 평가 결과:
  - **Correct: 14** (14%)
  - **Incorrect: 40**
  - **Uncertain: 9**
  - **No answer: 37**

**핵심 결론:**
> "answering questions about scholarly knowledge is a challenge for current QA systems and LLMs ... SciQA benchmark represents a challenging task for next-generation QA systems, as QA systems must now also deal with scientific knowledge in addition to encyclopedic knowledge." — 논문 p.4

## SciQA의 차별점 (Table 1, 다른 KG-QA 벤치마크 대비)
| Benchmark | Target KG | Questions | Domain | NL+SPARQL | Answers |
|---|---|---|---|---|---|
| WebQuestions | Freebase | 5,810 | 백과사전 | △ | ✓ |
| SimpleQuestions | Freebase | 108,442 | 백과사전 (factoid) | ✓ | × |
| LC-QuAD | DBpedia | 5,000 | 백과사전 (multi-hop) | ✓ | ✓ |
| LC-QuAD 2.0 | Wikidata+DBpedia | 30,000 | 백과사전 | ✓ | ✓ |
| QALD-10 | Wikidata | 394 | 백과사전 (4 langs) | ✓ | ✓ |
| **SciQA** | **ORKG** | **2,565** | **학술 (CS / engineering / bio / ecology / zoology / etc.)** | **✓** | **✓** |

SciQA만이 **학술 비교 데이터 + query shape/component 메타데이터**를 함께 제공.

## 한계점
- **Handcrafted set 100개로 소규모** — 다양한 도메인의 복잡한 질문을 망라하기엔 작음.
- **Autogenerated 2,465개는 CS(papers-with-code) 단일 도메인** → 도메인 편중 큰 비중.
- **자동 생성 질문은 Superlative/Temporal/Count 0개** (Factoid 위주) → 복잡도가 handcrafted보다 낮음.
- **ORKG 의존**: ORKG 큐레이션 시점에 따라 정답이 달라질 수 있음 (스냅샷 명시 필요).
- **언어**: 영어 단일 — QALD-10이 4언어 지원하는 것과 대조.
- **LLM의 SPARQL 생성 능력 평가 부재** — 단순 자연어 응답만 평가, 실제 KGQA 시스템에는 NL→SPARQL 변환 필요.
