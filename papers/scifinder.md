#### 📌 한 줄 요약
SciFinder-n은 미국화학회(ACS) CAS 부서가 운영하는 구독 기반 화학 문헌·물질 DB로, 합성 화학자들이 반응 검색, 물질 탐색, 특허 정보 접근에 가장 광범위하게 활용하는 상업용 인프라이다.

#### 🎯 개발/구축 배경
**기존 인프라의 한계**
- 화학 반응, 물질, 문헌 정보를 통합 검색하는 표준 상업 도구가 없었음
**이 시스템이 필요한 이유**
- 합성 화학자의 일상적 반응 탐색, 선행 기술 조사, 물질 특성 확인 수요
- 특허 및 저널 화학 정보의 통합 접근

#### 🔨 시스템 구성
CAS가 화학 문헌·특허에서 추출하여 큐레이션한 화합물, 반응, 문헌 데이터를 통합한다. CAS Registry Number(CAS 번호)가 각 화합물의 표준 식별자. 구조, 부분구조, 반응, 연구자, 주제 등 다양한 검색 방식 지원.

#### 📥 데이터 접근 방법
| 방법 | 설명 |
|---|---|
| 구독 플랫폼 | scifinder-n.cas.org (기관 구독 필요) |
| 구조 검색 | SMILES/구조 그리기 기반 검색 |
| 반응 검색 | 반응 유형·조건 기반 탐색 |

#### 📤 제공 데이터 형식
- 화합물 레코드 (CAS 번호, 구조, 성질)
- 반응 레코드 (반응물, 생성물, 조건, 수율)
- 문헌 및 특허 참조
- CAS 번호 (표준 식별자)

#### 📊 주요 통계 (논문 기준)
| 항목 | 수치 |
|---|---|

| 데이터 범위 | 구독 기반; CAS에서 공개적 수치 미발표 |

#### ⚠️ 한계점
- 구독 기반으로 오픈 과학 RAG 시스템이 직접 접근 불가
- 비용이 높아 소규모 기관 및 개발도상국 연구자 접근 제한
- 화학 RAG 인프라와의 가장 큰 격차 대표 사례
