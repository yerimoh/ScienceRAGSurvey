# MedRAGChecker: Claim-Level Verification for Biomedical Retrieval-Augmented Generation

> arXiv | 2026 | Method | medical · bio

## TL;DR
A verification framework that decomposes the long answers generated by medical-domain RAG systems into atomic units (Atomic Claims) and diagnoses factuality and safety by fusing text-based NLI with a knowledge graph (DRKG).

## Background and Motivation
- **Limitations of prior methods**: In medical-domain RAG, evaluation at the paragraph level or the whole-answer (Answer-level) level struggles to catch a critical single factual error buried deep within a long text. LLMs tend to judge something as correct as long as it exhibits a textually plausible correlation, even when it violates a causal relationship or a medical contraindication.
- **Why this research is needed**: To prevent safety-critical errors directly tied to safety, such as drug-disease prescriptions or side effects, cross-verification using not only textual context but also structured external medical knowledge (KG) is essential.

## Architecture

```
[LLM-generated answer (Raw Answer)]
      ↓
[Claim Extractor]
Decomposes the LLM answer into a list of Atomic Claims
in the form of SPO (Subject, Relation, Object) triples
      ↓
    ┌────────┴───────┐
[Textual NLI Checker]    [KG-Based Verifier]
Distilled student model ensemble      DRKG entity linking
 Entail/Contradict decision   TransE triple plausibility score
    └────────┬───────┘
      ↓
[Signal Fusion (Logit space)]
Outputs Faithfulness, Hallucination, SafetyErr scores
```

## Detailed Description of Core Modules
### Teacher-Student Distillation
- Instead of calling GPT-4.1 every time, uses the Claims and NLI labels generated by GPT-4.1 to SFT 7B–13B open-source medical LLMs (Meditron3-8B, Med42-Llama3-8B, etc.)
- Training data: Cross-entropy over NLI labels (Entail/Neutral/Contradict)

### F1-Weighted Ensemble
- Since the distilled student models show different strengths on particular classes (e.g., Neutral, Contradict), the per-class F1 scores measured on the Dev set are used as weights to ensemble the predictions

### KG Fusion (applying TransE)
- After mapping the entities of the extracted Claim to DRKG, a TransE embedding model is used to compute the plausibility score $p_{KGE}$ of the (h, r, t) triple, and this is combined with the textual signal

| Module | Tools/Models Used | Role and Characteristics |
|---|---|---|
| Claim Extractor | Meditron3-8B, etc. (SFT) | Splits the text answer into an SPO structured array (JSON) |
| NLI Checker | Student model ensemble | Determines Entail/Contradict for a Claim with the Context as premise |
| KG Verifier | DRKG, TransE | Filters structural medical contraindication/relation violations |

## Experiments and Evaluation
**Evaluation datasets**: PubMedQA, MedQuAD, LiveQA, MedRedQA

**Main results (by generator model)**
| Generator Model | Faithfulness | Hallucination | SafetyErr |
|---|---|---|---|
| Med-Qwen2-7B | 81.4% | 8.0% | 7.7% |
| Med42-Llama3-8B | 85.3% | 6.3% | 6.8% |
| Meditron3-8B | 71.5% | 7.6% | 8.2% |
| PMC-LLaMA-13B | 60.1% | 10.7% | 11.3% |

→ Compared to using plain text NLI alone, fusing the knowledge graph (KG) significantly improves verification agreement (against human expert ground truth) for safety-sensitive Claims.

## Key Contributions
1. Builds a pipeline that decomposes RAG outputs to a finer **Atomic Claim level**, rather than even individual sentences, for fine-grained diagnosis
2. Presents a methodology that does not leave hallucination verification to textual inference alone, but instead **combines unstructured text verification with a structured knowledge graph (KG)** to catch Safety-critical errors
3. Implements **F1-weighted ensemble small-checker modeling** to reduce dependence on costly APIs (GPT-4)

## Limitations
- For rare diseases or entities not included in the knowledge graph (DRKG), the fusion signal has no effect and the system must rely on text verification alone.
- Because the entity linking process relies on surface-level text matching, KG mapping can fail in multi-hop reasoning or complex contexts.
